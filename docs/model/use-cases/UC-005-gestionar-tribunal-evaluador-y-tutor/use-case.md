## Brief Description

El director de carrera designa al tutor y a los tres miembros del tribunal evaluador del proyecto de grado de cada estudiante, y el sistema notifica las designaciones al estudiante y a los docentes designados. Así queda registrado quién guía y quién evalúa cada proyecto.

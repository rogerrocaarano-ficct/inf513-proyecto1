## Brief Description

El estudiante entrega el documento del proyecto para la revisión del tribunal evaluador y del tutor, y entrega nuevas versiones con las correcciones a las observaciones recibidas. El sistema conserva el historial de versiones. Al final entrega el documento para la defensa final.

# ACT-008 Administrador

- **Type:** Primary
- **Kind:** Human
- **Generalizes:** ACT-010 Usuario

## Description

Responsable técnico que crea y mantiene las cuentas de usuario y sus roles. Usa el sistema para que cada participante tenga acceso según su rol.

## Goals

- Mantener las cuentas de usuario con sus roles (UC-001)
- Auditar los cambios de las cuentas de usuario (UC-009)

## Responsibilities

- Dar de alta, modificar y desactivar cuentas de usuario

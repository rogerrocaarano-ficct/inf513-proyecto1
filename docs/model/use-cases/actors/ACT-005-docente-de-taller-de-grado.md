# ACT-005 Docente de Taller de Grado

- **Type:** Primary
- **Kind:** Human

## Description

Docente de la materia Taller de Grado, único en la carrera, que evalúa la viabilidad de todos los perfiles de proyecto. Usa el sistema para registrar su evaluación del perfil.

## Goals

- Evaluar la viabilidad del perfil de proyecto (UC-006)

## Responsibilities

- Emitir el visto bueno o las observaciones del perfil de proyecto

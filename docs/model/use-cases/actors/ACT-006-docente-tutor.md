# ACT-006 Docente Tutor

- **Type:** Primary
- **Kind:** Human
- **Generalizes:** ACT-004 Docente

## Description

Docente designado como tutor del proyecto de grado de un estudiante, que lo guía y revisa el documento del proyecto antes que el tribunal evaluador. Usa el sistema para registrar sus observaciones y su aprobación del documento.

## Goals

- Revisar, observar y aprobar las versiones del documento del proyecto (UC-006)

## Responsibilities

- Revisar el documento del proyecto y registrar sus observaciones

# ACT-001 Estudiante

- **Type:** Primary
- **Kind:** Human

## Description

Postulante que realiza el trámite de titulación por Proyecto de Grado. Usa el sistema para presentar sus documentos y seguir el avance de su trámite.

## Goals

- Subir sus documentos iniciales (UC-002)
- Presentar su perfil de proyecto (UC-003)
- Entregar el documento del proyecto y sus correcciones (UC-007)
- Saber en qué etapa está su trámite (UC-012)
- Conocer las fechas de sus evaluaciones (UC-013)
- Mantener actualizada su foto de perfil (UC-016)

## Responsibilities

- Presentar los documentos iniciales, el perfil de proyecto y el documento del proyecto
- Subsanar las observaciones del docente de Taller de Grado, del tutor y del tribunal evaluador

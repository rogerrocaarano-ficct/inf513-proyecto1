## Brief Description

El administrador y el director de carrera crean, consultan, modifican, desactivan y reactivan cuentas de usuario y sus roles, cada uno dentro de su alcance: el administrador gestiona todas las cuentas, y el director de carrera, las de los docentes. Así cada participante del trámite de titulación puede usar el sistema según sus roles.

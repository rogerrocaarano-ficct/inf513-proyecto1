## Brief Description

El director de carrera programa la fecha, la hora y el lugar de cada defensa: la predefensa, que es la defensa interna, una vez aprobado el documento del proyecto, y la defensa final, que es la defensa pública, una vez aprobada la predefensa. El sistema notifica la programación al estudiante y al tribunal evaluador.

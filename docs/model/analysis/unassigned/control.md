| Status | Draft |

**Responsibilities:**

- Coordinar la presentación del perfil de proyecto y la entrega de las versiones del documento del proyecto sobre el trámite de titulación en curso del estudiante (UC-004)

## GestorTramites

| | |
| --- | --- |
| Use cases (derived) | UC-003 |
| Status | Draft |
| Iteration | I1 |

**Responsibilities:**

- Coordinar la apertura del trámite de titulación con la cuenta de usuario del estudiante, nueva o existente, que pide a GestorUsuarios (UC-003)

## GestorUsuarios

| | |
| --- | --- |
| Use cases (derived) | UC-001, UC-003 |
| Status | Draft |
| Iteration | I1 |

**Responsibilities:**

- Coordinar la creación, consulta, modificación, desactivación y reactivación de cuentas de usuario, dentro del alcance de quien lo solicita (UC-001)
- Advertir de los trámites de titulación en curso afectados por una desactivación o un rol quitado (UC-001)
- Obtener la cuenta de usuario activa del estudiante, o crearla con el rol de estudiante, cuando se abre su trámite de titulación; la autoriza la apertura del trámite, no el alcance de quien lo solicita (UC-003)
- Hacer que cada cambio quede en el registro de cambios y se notifique al usuario afectado (UC-001, UC-003)

## Requisitos funcionales

Estos requisitos fueron presentados originalmente por el equipo de desarrollo:

- RF01 - Registro de solicitud y apertura de expediente: El sistema debe permitir al secretario(a) registrar una nueva solicitud de titulación a nombre de un estudiante, ingresando sus datos y abriendo su expediente de titulación.
- RF02 - Registro y verificación de requisitos iniciales: El sistema debe permitir al secretario(a) marcar y registrar la recepción de los documentos físicos del estudiante: hoja de vida, fotocopia de cédula de identidad y boleta de inscripción de Modalidad de Graduación.
- RF03 - Asignación formal de docente tutor: El sistema debe permitir al director de carrera asignar y registrar al tutor académico asignado al estudiante.
- RF04 - Registro de entrega de perfil de proyecto: El sistema debe permitir al secretario(a) registrar la recepción del perfil de proyecto presentado por el estudiante.
- RF05 - Registro de visto bueno del perfil: El sistema debe permitir al secretario(a) registrar la aprobación formal (visto bueno) del perfil emitida por el docente de Taller de Grado.
- RF06 - Designación de tribunal evaluador: El sistema debe permitir al director de carrera designar a los tres docentes que conformarán el tribunal calificador del estudiante.
- RF07 - Notificación a miembros del tribunal: El sistema debe notificar a los docentes designados sobre su nombramiento como miembros del tribunal evaluador.
- RF08 - Registro de entrega de documento para revisión: El sistema debe permitir registrar la entrega formal del documento del proyecto para la revisión del tribunal evaluador.
- RF09 - Registro de observaciones del tribunal: El sistema debe permitir a los docentes del tribunal (o al secretario(a) en base a la carta formal dirigida a la dirección) registrar las observaciones emitidas al documento.
- RF10 - Control de subsanación de observaciones: El sistema debe permitir registrar las respuestas y correcciones del estudiante ante las observaciones emitidas, manteniendo el historial de versiones o revisiones.
- RF11 - Aprobación del documento por parte del tribunal: El sistema debe registrar la conformidad y visto bueno de los tres miembros del tribunal sobre el documento final.
- RF12 - Programación de predefensa y revisión de prototipo: El sistema debe permitir al secretario(a) registrar la fecha, hora y lugar asignados para la predefensa y revisión técnica del prototipo.
- RF13 - Notificación de fecha de predefensa: El sistema debe notificar al estudiante y al tribunal evaluador la programación de la predefensa.
- RF14 - Registro de resultado y observaciones de predefensa: El sistema debe permitir registrar el resultado de la predefensa y asentar las observaciones finales que requieran subsanación previa a la defensa final.
- RF15 - Programación de defensa pública final: El sistema debe permitir al secretario(a) agendar la fecha, hora y aula/recinto para la defensa pública final, una vez cumplida y aprobada la etapa de predefensa.
- RF16 - Registro de calificación y acta de graduación: El sistema debe permitir registrar el resultado, la calificación final asignada por el tribunal y emitir los datos para el acta de graduación.
- RF17 - Registro de entrega de ejemplares físicos: El sistema debe permitir al secretario(a) certificar la recepción de las dos copias físicas del proyecto/tesis (una para biblioteca y una para dirección de carrera).
- RF18 - Cierre y archivo del expediente: El sistema debe permitir dar por concluido el trámite de titulación y archivar el expediente del graduado.
- RF19 - Consulta de estado y seguimiento del trámite: El sistema debe permitir al estudiante, docentes del tribunal, secretario(a) y director de carrera consultar en qué etapa del proceso se encuentra un trámite de titulación específico.

## CASOS DE USO (APROBADOS)

- CU1. Gestión de Usuarios(Director, Académico, Tutor, Tribunal Estudiante, Secretaria) - Fotos.
- CU2. Gestión de Habilitación Académica de Solicitudes.
- CU3. Gestión de Asignación Tutor y Registro Perfil de Proyecto.
- CU4. Gestión de Evaluación de Viabilidad y Conformar Cuerpo de Tribunales.
- CU5. Gestión de Revisión, Versionado y Control de Plazos de Tribunales.
- CU6. Gestión de Programación y Registrar Evaluaciones (Predefensa y Defensa Final).
- CU7. Gestión de Monitoreo Trazabilidad, Dashboard y Calendario Académico.
- CU8. Reportes y Estadísticas.

# UC-008 Reportes y estadísticas

> Primera versión, pendiente de revisión: los reportes, sus indicadores y quién los pide no están definidos.

## Objetivo

La dirección de carrera obtiene reportes y estadísticas de titulación a partir de los trámites registrados, sin revisar las carpetas una por una.

## Actores

| Actor | Participación |
| --- | --- |
| Director de carrera | Principal: pide los reportes y estadísticas de titulación |

## Precondiciones

- Quien hace la solicitud tiene una cuenta de usuario activa.

## Flujo básico: obtener un reporte de titulación

1. El director de carrera pide un reporte de titulación, indicando el periodo (FR-029).
2. El sistema comprueba que su rol le permite pedirlo.
3. El sistema calcula las estadísticas a partir de los trámites de titulación registrados en ese periodo, en curso y cerrados.
4. El sistema responde solo al director con el reporte.

## Excepciones

En todos los casos el sistema informa el motivo a quien hizo la solicitud.

| ID | Dónde | Situación |
| --- | --- | --- |
| E1 | Todos | Quien hace la solicitud no tiene una cuenta activa o su rol no le permite hacerla |
| E2 | Flujo básico, paso 1 | El periodo no es válido |

## Postcondiciones

- El reporte no cambia datos ni avisa a otros usuarios: la respuesta llega solo a quien lo pidió.

## Reglas de negocio

- Las estadísticas se obtienen solo de los trámites registrados en el sistema.

## Requisitos relacionados

FR-029, NFR-002, NFR-003.

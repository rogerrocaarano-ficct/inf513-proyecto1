# UC-005 Revisión y versionado del documento del proyecto

## Objetivo

El estudiante obtiene la aprobación del documento del proyecto por su tutor y por los tres miembros de su tribunal evaluador, para quedar apto para la predefensa. Cada versión entregada y cada revisión con sus observaciones quedan registradas y se pueden consultar.

## Actores

| Actor | Participación |
| --- | --- |
| Estudiante | Principal: entrega el documento del proyecto y, si se lo observan, una versión corregida |
| Tutor | Revisa primero cada versión: la aprueba o la observa |
| Miembro del tribunal | Revisa cada versión que el tutor aprobó: la aprueba o la observa |
| Secretario(a) de dirección de carrera | Recibe el aviso del documento aprobado |
| Director de carrera | Recibe el aviso del documento aprobado, para programar la predefensa (UC-006) |

## Precondiciones

- El estudiante tiene un trámite de titulación en curso (UC-002), con el perfil de proyecto aprobado (UC-004), tutor asignado y los tres miembros del tribunal designados (UC-003).

## Flujo básico: entregar una versión del documento del proyecto

1. El estudiante entrega el documento del proyecto en PDF, con un comentario general sobre la versión (FR-008, FR-010).
2. El sistema comprueba que el estudiante puede entregarla: es la primera versión, o el tutor observó la versión vigente, o los tres miembros del tribunal la revisaron y al menos uno la observó (FR-040).
3. El sistema registra la versión como la versión vigente y conserva las anteriores con sus revisiones (FR-010).
4. El sistema envía la versión al tutor para que la revise (FR-041).

## Flujos alternativos

Cada versión se revisa en dos etapas: primero el tutor y, si la aprueba, los miembros del tribunal (FR-044). Cada revisor registra una sola revisión por versión, aprobada u observada, con sus observaciones en texto y, si quiere, un PDF anotado (FR-009, FR-045).

### A1. El tutor aprueba la versión

1. El tutor aprueba la versión vigente (FR-009).
2. El sistema registra la revisión del tutor.
3. El sistema pasa la versión a los tres miembros del tribunal y les avisa para que la revisen (FR-044).
4. El sistema avisa al estudiante que el tutor aprobó la versión y que pasó al tribunal (FR-046).

### A2. El tutor observa la versión

1. El tutor observa la versión vigente e indica sus observaciones; puede adjuntar el PDF anotado (FR-009).
2. El sistema registra la revisión del tutor. La versión no pasa al tribunal (FR-044).
3. El sistema avisa al estudiante con las observaciones del tutor (FR-046). El estudiante puede entregar una versión corregida (flujo básico).

### A3. Un miembro del tribunal revisa la versión

1. Un miembro del tribunal aprueba u observa la versión vigente que el tutor aprobó; si la observa, indica sus observaciones y puede adjuntar el PDF anotado (FR-009).
2. El sistema registra la revisión del miembro.
3. Mientras falten revisiones de los miembros del tribunal, el sistema no avisa al estudiante.
4. Cuando los tres miembros revisaron la versión:
   - Si al menos uno la observó, el sistema avisa al estudiante el resultado y las observaciones de cada miembro (FR-047). El estudiante puede entregar una versión corregida (flujo básico).
   - Si los tres la aprobaron, el documento del proyecto queda aprobado y apto para la predefensa (FR-011). El sistema avisa al estudiante, al secretario(a) y al director de carrera (FR-048).

### A4. Entregar la versión para la defensa final

1. Después de aprobar la predefensa (UC-006), el estudiante entrega la versión para la defensa final (FR-025).
2. La versión se revisa en las mismas dos etapas, por el tutor (A1, A2) y por los miembros del tribunal (A3) (FR-043).
3. Cuando el tutor y los tres miembros la aprueban, queda lista para la defensa final (UC-006).

## Excepciones

En todos los casos el sistema informa el motivo a quien hizo la solicitud y no registra nada.

| ID | Dónde | Situación |
| --- | --- | --- |
| E1 | Todos | Quien hace la solicitud no tiene una cuenta activa o su rol no le permite hacerla |
| E2 | Todos | El trámite no existe o no está en curso |
| E3 | Flujo básico, paso 1 | El estudiante no tiene el perfil de proyecto aprobado, no tiene tutor asignado o su tribunal no tiene los tres miembros designados |
| E4 | Flujo básico, paso 2 | La versión vigente todavía está en revisión o ya fue aprobada (FR-040) |
| E5 | Flujo básico, paso 1 | Falta el comentario general, o el documento no es un PDF o supera el tamaño máximo (NFR-005) |
| E6 | A1, A2, A3 | Quien revisa no es el tutor ni un miembro del tribunal de ese trámite |
| E7 | A1, A2, A3 | No hay una versión pendiente de su revisión, o ya registró su revisión de esa versión (FR-045) |
| E8 | A3 | El tutor todavía no aprobó la versión (FR-044) |
| E9 | A2, A3 | Quien observa no indicó observaciones |

## Postcondiciones

- Flujo básico: el trámite tiene una versión vigente nueva, y el tutor la recibió.
- A1: la versión está en revisión del tribunal, los tres miembros la recibieron y el estudiante recibió el aviso.
- A2, A3 con observaciones: el estudiante recibió las observaciones y puede entregar una versión corregida.
- A3 con las tres aprobaciones: el documento del proyecto está aprobado y apto para la predefensa.
- Las versiones anteriores y sus revisiones se conservan.

## Reglas de negocio

- Cada versión se revisa en dos etapas: el tutor, como filtro previo, y después los tres miembros del tribunal. Si el tutor la observa, el tribunal no la ve (FR-040, FR-044).
- La revisión de las versiones empieza solo cuando el trámite tiene tutor y los tres miembros del tribunal designados.
- Cada revisor registra una sola revisión por versión, y una revisión registrada no se cambia (FR-045).
- Las revisiones no tienen plazo: cada versión espera la revisión del tutor y de los tres miembros del tribunal.
- El documento queda apto para la predefensa solo cuando lo aprueban el tutor y los tres miembros del tribunal (FR-011).
- El estudiante entrega una versión nueva solo cuando el tutor observó la vigente, o cuando los tres miembros la revisaron y al menos uno la observó (FR-040).
- La versión para la defensa final se entrega después de aprobar la predefensa y se revisa en las mismas dos etapas (FR-025, FR-043).

# UC-004 Evaluación del perfil de proyecto

## Objetivo

El estudiante obtiene la aprobación de su perfil de proyecto por el docente de Taller de Grado, que evalúa su viabilidad. Cada perfil presentado y cada evaluación quedan registrados y se pueden consultar.

## Actores

| Actor | Participación |
| --- | --- |
| Estudiante | Principal: presenta el perfil de proyecto y, si se lo observan o rechazan, una versión nueva |
| Docente de Taller de Grado | Evalúa el perfil: lo aprueba, lo observa o lo rechaza |
| Director de carrera | Recibe el aviso del perfil aprobado, para asignar el tutor (UC-003) |

## Precondiciones

- El estudiante tiene una cuenta de usuario activa y un trámite de titulación en curso (UC-002).
- Hay un docente de Taller de Grado activo (FR-039).

## Flujo básico: presentar el perfil de proyecto

1. El estudiante presenta su perfil de proyecto: el título del proyecto y el documento en PDF.
2. El sistema comprueba que el estudiante puede presentarlo: no tiene perfil, o su último perfil fue observado o rechazado (FR-058).
3. Si es el primer perfil, el sistema crea el proyecto de grado del trámite. Si no, registra el perfil como versión nueva del anterior, que se conserva junto con su evaluación (FR-023).
4. El sistema registra el perfil como **pendiente**, con el título indicado (FR-004).
5. El sistema envía el perfil al docente de Taller de Grado (FR-057).

## Flujos alternativos

El docente de Taller de Grado evalúa el perfil pendiente de un trámite. Cada evaluación queda registrada con su resultado, sus observaciones y su fecha.

### A1. Aprobar el perfil

1. El docente de Taller de Grado aprueba el perfil pendiente del trámite (FR-005).
2. El sistema registra el perfil como **aprobado**.
3. El sistema avisa al estudiante (FR-060) y al director de carrera (FR-061). El proyecto queda listo para la asignación del tutor (UC-003).

### A2. Observar el perfil

1. El docente de Taller de Grado observa el perfil pendiente del trámite e indica sus observaciones: cambios que el estudiante debe hacer, por ejemplo de forma (FR-022).
2. El sistema registra el perfil como **observado**, con las observaciones.
3. El sistema avisa al estudiante con las observaciones (FR-060). El estudiante puede presentar una versión nueva (flujo básico).

### A3. Rechazar el perfil

1. El docente de Taller de Grado rechaza el perfil pendiente del trámite e indica el motivo: el tema del proyecto debe cambiar (FR-022).
2. El sistema registra el perfil como **rechazado**, con las observaciones.
3. El sistema avisa al estudiante con las observaciones (FR-060). El estudiante puede presentar una versión nueva con otro tema (flujo básico).

## Excepciones

En todos los casos el sistema informa el motivo a quien hizo la solicitud y no registra nada.

| ID | Dónde | Situación |
| --- | --- | --- |
| E1 | Todos | Quien hace la solicitud no tiene una cuenta activa o su rol no le permite hacerla |
| E2 | Flujo básico, paso 2 | El estudiante no tiene un trámite en curso |
| E3 | Flujo básico, paso 2 | El último perfil del estudiante está pendiente o aprobado (FR-058) |
| E4 | Flujo básico, paso 1 | Falta el título, o el documento no es un PDF o supera el tamaño máximo (NFR-005) |
| E5 | Flujo básico, paso 5 | No hay un docente de Taller de Grado activo; el estudiante puede volver a presentarlo más adelante |
| E6 | A1, A2, A3 | El trámite no existe, no está en curso o no tiene un perfil pendiente |
| E7 | A2, A3 | El docente no indicó observaciones |

## Postcondiciones

- Flujo básico: el trámite tiene un perfil pendiente, y el docente de Taller de Grado lo recibió.
- A1, A2, A3: el perfil tiene su evaluación registrada, y el estudiante (y en A1, el director de carrera) recibió el aviso.
- Las versiones anteriores del perfil y sus evaluaciones se conservan.

## Reglas de negocio

- El perfil pasa por los estados pendiente, aprobado, observado y rechazado. Solo se evalúa un perfil pendiente.
- Observar pide cambios sobre el mismo tema; rechazar pide cambiar el tema. Ambos permiten presentar una versión nueva (FR-023, FR-058).
- El título del proyecto puede cambiar en cada versión. El sistema no compara títulos: si el tema cambió lo juzga el docente de Taller de Grado.
- La carrera tiene un solo docente de Taller de Grado, que evalúa todos los perfiles (FR-039).
- El tutor se asigna solo a un proyecto con el perfil aprobado (FR-003, UC-003).
